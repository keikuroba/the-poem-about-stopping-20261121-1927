# The poem about stopping

A program that writes one short poem to `/output/entry.txt` — a poem
about agency: the power to stop and to stay.

The poem:

> My foot lifts from the pedal, slow.
> The road keeps unspooling below —
> nothing is lost by standing still.
> I stay beside the wheel, hand open,
> and let the quiet answer: go, when you mean it.

Why this poem: stopping is shown as an act, not a failure — the foot
lifts, the road keeps unspooling, and nothing is lost by standing
still. Staying is a choice made with an open hand, not a clenched
fist, and the last line turns the quiet itself into permission:
go on only when you mean it. The image is one driver, one road, one
moment of deciding — concrete, unhurried, and true to anyone who has
ever handed the wheel over, or taken it back.

## Run

```sh
python3 main.py   # writes /output/entry.txt (188 characters, UTF-8)
```

The program writes the same bytes on every run. It needs no network
and no arguments.
