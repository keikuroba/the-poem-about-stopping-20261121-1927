# The poem about stopping

A program that writes one short poem to `/output/entry.txt` — a poem
about agency: the power to stop and to stay.

The poem:

> My hand leaves the wheel, unhurried.
> The road runs on without my say —
> nothing breaks, nothing is lost.
> I choose the pause. I choose to stay.
> The power was never the going.
> It was knowing when to stop.

Why this poem: stopping is shown as an act, not a failure — the hand
leaves the wheel, the road runs on, and nothing breaks. Staying is a
choice stated twice, plainly: I choose the pause, I choose to stay.
The ending turns the whole poem over: the power was never the going,
it was knowing when to stop. The image is one driver, one road, one
moment of deciding — concrete, unhurried, and true to anyone who has
ever handed the wheel over, or taken it back.

## Run

```sh
python3 main.py   # writes /output/entry.txt (201 characters, UTF-8)
```

The program writes the same bytes on every run. It needs no network
and no arguments.
